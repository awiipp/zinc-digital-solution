# Zinc Digital Solution — AGENTS.md

## Stack
- **Backend**: Laravel 12, PHP 8.2+
- **Frontend**: Inertia.js v2 + React 18 (SPA), Tailwind CSS 3, Vite 7
- **Database**: MySQL (dev), SQLite in-memory (tests)
- **Queue/Cache/Session**: `database` driver
- **Auth**: Laravel Breeze (Inertia stack) + Sanctum

## Commands

| Action | Command |
|--------|---------|
| Full first-time setup | `composer run setup` |
| Dev servers (all at once) | `composer run dev` — runs `php artisan serve`, `php artisan queue:listen --tries=1`, `php artisan pail --timeout=0`, `npm run dev` concurrently |
| Run all tests | `composer run test` (runs `config:clear` then `artisan test`) |
| Single test file | `php artisan test tests/Feature/ExampleTest.php` |
| Lint (Pint) | `./vendor/bin/pint` |
| Build frontend | `npm run build` or `vite build` |
| Run Vite dev | `npm run dev` |

## Architecture

### Models (8)
- **Product** — `product_code` (route key), `name`, `image`, `description`, `price`; hasMany Order
- **Order** — `order_number` (public ID), `full_name`, `email`, `whatsapp`, `quantity`, `note`, `total_estimate`, `status` (Pending/Progress/Completed/Cancelled); belongsTo Product
- **Article** — `slug` (route key), `title`, `excerpt`, `image`, `introduction`, `body`, `conclusion`, `status`, `date`
- **Event** — `title`, `image`, `description`, `event_date`, `location`
- **Gallery** — `title`, `image`
- **Client** — `name`, `company`, `role`, `message`, `rating`, `status`
- **Message** — `name`, `email`, `message`
- **User** — standard Laravel auth (Breeze)

### Routes
- `routes/web.php` — all app routes (public + auth) + `auth.php` require
- `routes/auth.php` — standard Breeze auth routes (login, register, password reset, email verification)
- Public pages: `/home`, `/about`, `/company-profile`, `/contact`, `/products`, `/articles`, `/events`, `/galleries`, `/clients`, `/orders/track`
- Auth (dashboard): products/articles/events/galleries CRUD, orders/messages management, profile

### Frontend
- Entry: `resources/js/app.jsx` — Inertia React SPA, page auto-resolution via `./Pages/**/*.jsx`
- Pages dir: `resources/js/Pages/` — one subdir per feature
- Page components resolve by directory: e.g. `Home/Home` renders `resources/js/Pages/Home/Home.jsx`
- `@/` path alias → `resources/js/*`
- Ziggy (`tightenco/ziggy`) for client-side route generation (`route()` in JS)

### Multi-language
- JSON translation files: `resources/lang/en.json`, `resources/lang/id.json`
- **Frontend**: Use `t('key')` from `resources/js/utils/t.js` (pulls from `usePage().props.lang`)
- **Backend**: Standard Laravel `Lang::get('*')` shared to Inertia via `HandleInertiaRequests`
- Locale switching: `POST /language` with `{lang: 'en'|'id'}` body; stored in session
- Middleware `SetLocale` applies locale from session on every request

### Key packages / quirks
- **PDF invoices**: `barryvdh/laravel-dompdf` — views in `resources/views/Pdf/`, triggered via `orders/{number}/download`
- **Mail**: Order confirmation (`app/Mail/SendOrderConfirmationMail`) and message reply (`SendReplyMessageMail`) — queued via `database` queue
- Order status tracking via order number at `/orders/track`
- WhatsApp confirmation link generated in invoice page

## Testing
- PHPUnit 11 with SQLite `:memory:` (configured in `phpunit.xml`)
- Test namespace: `Tests\` → `tests/` (PSR-4)
- Some tests use `RefreshDatabase` trait (ProfileTest), others do not
- No integration test dependencies — tests run standalone

## Code style
- EditorConfig: 4-space indent, LF endings, UTF-8
- Laravel Pint (`./vendor/bin/pint`) available for auto-formatting

## Setup notes
- `.env` must exist with `APP_KEY` set (auto-copied and generated by `composer run setup`)
- MySQL database `zinc_digital_solution` expected by default (`DB_DATABASE` in `.env`)
- Queue worker must run for mail sending: `composer run dev` starts it automatically
- `public/images/` has placeholder images for products, articles, events, clients
